# Development Guide — backtest/

## OVERVIEW
Backtest system: 7 engines, 6 data loaders, optimizers, runner, validation.

## STRUCTURE
```
backtest/
├── engines/            # 7 engines + composite cross-market engine + options_portfolio
│   ├── base.py         # Shared bar-by-bar execution loop (705 LOC)
│   └── ...             # Equity, Futures, Crypto, Forex, Options, Composite
├── loaders/            # 6 sources: tushare, okx, yfinance, akshare, ccxt, futu
│   ├── base.py         # DataLoader protocol
│   └── registry.py     # Auto-fallback chains
├── optimizers/         # MVO, equal vol, max div, risk parity
├── benchmark.py        # Benchmark comparison (SPY, CSI 300 via yfinance)
├── correlation.py      # Rolling return correlation matrix
├── metrics.py          # Metrics calculation (Sharpe, max drawdown, etc.)
├── models.py           # Data models (run config, results)
├── run_card.py         # Reproducible run cards (run_card.json/md)
├── runner.py           # Entrypoint: config parsing, loader selection, engine routing (617 LOC)
└── validation.py       # Monte Carlo, Bootstrap CI, Walk-Forward
```

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Add engine | `engines/<name>.py` | Inherit from `base.py`, implement bar-by-bar loop |
| Add loader | `loaders/<name>.py` | Implement `DataLoader` protocol, register in `registry.py` |
| Add optimizer | `optimizers/<name>.py` | Portfolio weight allocation strategy |
| Add validator | `validation.py` | Statistical validation method |

## CONVENTIONS
- **`base.py`**: All engines inherit shared `BacktestEngine` — common bar-by-bar loop, position tracking, PnL calculation.
- **DataLoader protocol**: `load(symbol, start, end, **kwargs)` → `pd.DataFrame` with OHLCV columns.
- **Registry auto-fallback**: If primary source fails, tries next (e.g., Tushare → AKShare).
- **Run artifacts**: Every run outputs to `{run_dir}/` with `equity.csv`, `metrics.csv`, `trades.csv`.
- **Run cards**: `run_card.json` + `run_card.md` emitted alongside artifacts for reproducible research.

## ANTI-PATTERNS
- **Never** bypass `runner.py` for execution — it handles config parsing, engine selection, artifact collection.
- **Never** hardcode data sources — use `loaders/registry.py` for fallback chains.
- **Don't** skip `safe_run_dir()` validation — all run directory paths must be sandboxed.
- **Don't** mutate equity/metrics CSVs directly — they're generated by the engine.
